# Genki

App de suivi sport & physique (iOS, usage perso) — SwiftUI + SwiftData, sans backend. Voir `project.yml` (XcodeGen) pour la config du projet.

Les données de test dans `ObjectifsFit/Seed/SeedData.swift` sont fictives — aucune donnée de santé personnelle réelle n'est commitée dans ce repo ni dans son historique.
